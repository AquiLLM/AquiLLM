`OFL-Lexend.txt` preserves both the font's 2019 attribution and the upstream
Google Fonts license header (2018, with reserved font name RevReading Lexend):
https://raw.githubusercontent.com/google/fonts/main/ofl/lexend/OFL.txt .

`OFL-OpenDyslexic3.txt` preserves the older 2012 Abelardo Gonzalez attribution.
The leading heart glyph was mojibake in the embedded metadata and is normalized
for readability in the text notice only. The font binary is unchanged. Full OFL
1.1 terms accompany that attribution. The author's release page identifies
OpenDyslexic3 as SIL OFL: https://antijingoist.itch.io/opendyslexic .
The original download of this already-vendored binary has not been hash-matched
to an upstream release; the existing embedded attribution is the evidence used.

The unused older OpenDyslexic WOFF and the Microsoft Comic Sans TTF were removed.
Keep these text notices alongside the remaining fonts when redistributing them.
