Features
========

- **Document Collections** — Group and organize your documents for AI-powered retrieval
- **Chat with Documents** — Ask questions and get answers backed by your document library
- **Zotero Integration** — Sync your Zotero library directly into AquiLLM
- **Collaborative Sharing** — Share collections with team members
- **Custom Skills** — Add Markdown instructions through collections (shared instances), or Python tools if you run the server
- **Feedback System** — Rate answers and provide feedback to improve results
