=======================
Creating a collection
=======================

Name and create
===============

1. When on the **My Collections** page, click **New Collection**.
2. Enter a name and click **Create**.

.. figure:: /_static/images/creatingCollections/naming_collection.png
   :alt: Create New Collection dialog with collection name field and Create button
   :width: 800px
   :align: center

   Name your collection, then confirm with **Create**.

Empty list after creation
=========================

Right after you create it, **My Collections** should look similar to the screenshot below: your new collection appears as a card, and it is still **empty** (**0 documents**, **0 subcollections**) until you add files.

.. figure:: /_static/images/creatingCollections/post_creation_collections_page.png
   :alt: My Collections with one new collection card showing zero documents and zero subcollections
   :width: 800px
   :align: center

   Expected view right after creation: the collection exists but has no documents yet.

Upload and submit
=================

Open the collection from that card to reach its page. Add files by dragging and dropping, or click the upload area to choose files from your computer. Use the icons beside the upload area for other source types (for example audio or links) where available. When you are ready, click **Submit All** to add staged files to the collection.

.. figure:: /_static/images/creatingCollections/collections_full_detail.png
   :alt: Collection page with drag and drop upload, Submit All, and empty Browse table
   :width: 800px
   :align: center

   Empty collection: stage files, then **Submit All**.

.. admonition:: Upload tip

   Uploading multiple documents at once may be unreliable right now. If you run into issues, upload them **one at a time**.

.. figure:: /_static/images/creatingCollections/uploading_files_to_collection.png
   :alt: File picker over collection upload area with staged PDF and Submit All
   :width: 800px
   :align: center

   Selecting a file from disk; staged files appear above **Submit All**.

Browse results
==============

After submission, items appear in the **Browse** table. PDFs may show a related sub-collection (for example for figures) depending on how the document was processed.

.. figure:: /_static/images/creatingCollections/collection_post_upload.png
   :alt: Collection Browse table listing uploaded PDF and a figures sub-collection
   :width: 800px
   :align: center

   Uploaded items listed under **Browse**.

From the sidebar you can return to **My Collections** whenever you want to switch collections or create another one.
