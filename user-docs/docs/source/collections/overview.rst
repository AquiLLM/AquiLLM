============
Collections
============

What is a collection?
=====================

- A collection is a **group of documents** that AquiLLM can use when answering your questions.
- You create collections by uploading documents you want AquiLLM to reference.
- During creation, documents are split into smaller pieces called **chunks** and processed for information retrieval.
- This processing step may take some time, depending on the size of your documents.

My Collections page
===================

Open **Collections** in the left menu to reach **My Collections**. From there you can create a new collection or look at existing ones.
